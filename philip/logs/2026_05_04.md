### Warum Submodules?
- Repos bleiben separat und können ohne das "Parent" gecloned werden
- Als Default werden die Submodule nicht kopiert sondern nur ein Pointer auf einen bestimmten Commit, dh. freie Entscheidung ob Code auf dem aktuellen Computer relevant oder nicht.

> Um die Submodule dann tatsächlich zu pullen reicht ein kurzes Command:
> 
```sh
git submodule update
```
