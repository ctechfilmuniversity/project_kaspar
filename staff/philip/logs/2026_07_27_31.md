> Concluding the interconnection Odyssee

Throughout recent weeks I had a hard time wrapping my head around developing network architecture since this is something that apart from API calls and Javascript, I have not done before. Specifically designing a solid, scalable way to allow flexibel IPC between the components that make up the K.ai pipeline.

### Main Issues

- Versioning **without** duplicating code across modules or releasing prebuilt packages
- University Firewall blocking all non-standard ports
- IPC in general (lack of experience)


### Solutions

> Introduction of the `kai-shared` submodule

With the help of `uv` this can be added to all segments in the pipeline giving straight-forward access as if it were an installed Python package. All that's necessary is a small change in the `pyporject.toml`.

```toml
[project]
name = "kai-modname"
version = "0.1.0"
description = "This is an example."
readme = "README.md"
requires-python = "~=3.14.0"
dependencies = [
  "kai-shared",
  "..."
]

[tool.uv.sources]
kai-shared = { path = "./<location of the submodule>", editable = true }
```
